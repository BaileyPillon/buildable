# Buildable: spec (source of truth for every agent)

## One line
Drop a bank or card statement. Buildable finds every recurring charge and sorts each into what to
do about it, including three options that only exist now that Claude exists:
**ABSORB** (Claude already does this job), **REBUILD** (Claude Code builds you a free personal
version in a weekend), **SELF-HOST** (an old device in your drawer runs the open-source equivalent).
Classic options too: **HAGGLE**, **ROTATE**, **CANCEL**, **KEEP**. Output: a "subscription tax"
receipt and a build queue ranked by dollars saved per hour of building, each with a copy-paste
Claude Code prompt. 100% in the browser; a strict Content-Security-Policy makes uploading the
statement impossible.

Inspired by Nick Saraev, "31 Life-Changing Ways to Use Claude in 2027"
(https://youtu.be/KDyPHt4lW60): #10 cancel subscriptions by building replacements (3:45),
#25 replace a paid baby-tracking app (10:43), #11 agents that haggle (4:08), #4 and #8 old
Kindle and iPad as home devices (1:42, 3:01).

## Stack
- Vite + React 18 + TypeScript (strict). Vitest for tests. `papaparse` for CSV.
- Fonts self-hosted via `@fontsource/instrument-serif`, `@fontsource/inter`,
  `@fontsource/jetbrains-mono` (no Google Fonts: CSP is `font-src 'self'`).
- No backend, no analytics, no external requests at runtime.
- `vercel.json` sets these headers on every route:
  `Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self'; connect-src 'self'; frame-ancestors 'none'; form-action 'none'; base-uri 'self'; object-src 'none'`
  plus `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`.
  (connect-src 'self' only allows fetching our own static files such as the sample CSV.)

## Shared types (`src/types.ts`, verbatim)
```ts
export type Txn = {
  date: string;            // YYYY-MM-DD
  description: string;     // raw descriptor as exported
  amount: number;          // POSITIVE = money out (a charge). Negative = money in (refund, payment, deposit)
  source?: string;         // file name
};

export type Cadence = 'weekly' | 'biweekly' | 'monthly' | 'quarterly' | 'semiannual' | 'annual';

export type RecurringSeries = {
  key: string;                       // stable id: merchant id if KB-matched, else normalized key + amount cluster
  displayName: string;
  descriptors: string[];             // distinct raw descriptors seen, max 5
  cadence: Cadence;
  charges: { date: string; amount: number }[];   // ascending by date
  currentAmount: number;             // most recent charge
  annualCost: number;                // currentAmount * periods per year
  firstSeen: string;
  lastSeen: string;
  active: boolean;                   // lastSeen >= statementEnd - 1.5 * cadence days
  priceChanges: { date: string; from: number; to: number }[];
  confidence: number;                // 0..1
  merchantId: string | null;         // KB match, if any
  candidates?: string[];             // merchant ids, for ambiguous bundles (APPLE.COM/BILL, GOOGLE *)
};

export type Verdict = 'absorb' | 'rebuild' | 'selfhost' | 'haggle' | 'rotate' | 'cancel' | 'keep';

export type Category =
  | 'ai' | 'productivity' | 'health-family' | 'storage-security-home'
  | 'streaming-media' | 'telecom-utilities-finance' | 'software-learning' | 'shopping-news-social';

export type Device =
  | 'old-laptop' | 'spare-pc' | 'raspberry-pi' | 'nas' | 'old-android' | 'old-iphone' | 'old-ipad' | 'kindle';

export type Merchant = {
  id: string;                        // kebab-case, unique
  name: string;                      // "Netflix"
  category: Category;
  url: string;                       // official site
  match: {
    patterns: string[];              // case-insensitive RegExp sources, tested against the NORMALIZED descriptor
    examples: string[];              // 2-4 realistic raw statement descriptors (used for collision tests)
    billedVia?: 'direct' | 'apple' | 'google' | 'paypal' | 'amazon';
    priceHints?: { amount: number; cadence: Cadence; plan: string }[];   // US prices, used for APPLE.COM/BILL disambiguation
  };
  typicalMonthly: number | null;     // USD, most common US plan
  pricesCheckedAt: string;           // 'YYYY-MM'
  verdict: Verdict;                  // primary recommendation
  also?: Verdict[];                  // secondary options worth showing
  why: string;                       // <= 220 chars, plain reasoning for the primary verdict
  alternatives?: { name: string; url: string; note: string }[];  // free or cheaper swaps
  plans: {
    absorb?: { claudeDoes: string; howTo: string; limits: string; prompt: string };
    rebuild?: { whatYouBuild: string; hours: number; runsOn: string; ongoingCostYear: number; youLose: string; prompt: string };
    selfhost?: { software: string[]; hardware: Device[]; hours: number; powerCostYear: number; youLose: string; prompt: string };
    haggle?: { leverage: string; script: string; expectedDiscountPct: [number, number]; bestTime: string };
    rotate?: { pattern: string; monthsOffPerYear: number };
    cancel: { howTo: string; url?: string; gotchas?: string };   // ALWAYS present
  };
  sources: string[];                 // URLs backing prices, cancel steps, feature claims
};

export type Context = {
  claudePlan: 'none' | 'pro' | 'max';
  devices: Device[];
  unused: string[];                  // series keys the user flagged "barely use this"
  hourlyValue: number;               // $/hour the user values their time; default 25
  verdictOverrides: Record<string, Verdict>;   // series key -> verdict chosen by user
  merchantOverrides: Record<string, string>;   // series key -> merchant id (picked from candidates)
};

export type Assessment = {
  series: RecurringSeries;
  merchant: Merchant | null;
  verdict: Verdict;
  savingsYear: number;               // first-year USD saved if the user follows the verdict
  hours: number;                     // effort, hours (0 for keep/cancel, ~0.5 for haggle, plan hours otherwise)
  roiPerHour: number | null;         // savingsYear / hours, null if hours == 0
  blocked?: string;                  // e.g. "Needs an old laptop, Raspberry Pi or NAS"
  reason: string;                    // one sentence shown on the card
};

export type Summary = {
  statementStart: string; statementEnd: string;
  totalYear: number;                 // all ACTIVE recurring series
  byVerdict: Record<Verdict, { count: number; costYear: number; savingsYear: number }>;
  savingsYear: number;               // sum of unblocked savings
  buildHours: number;                // hours for absorb + rebuild + selfhost items
  claudeCostYear: number;            // added cost if claudePlan === 'none' and any absorb verdicts are counted (Pro, annual)
  netSavingsYear: number;            // savingsYear - claudeCostYear
};
```

## Engine public API (`src/engine/index.ts`)
```ts
export async function parseFiles(files: { name: string; text: string }[]): Promise<{ txns: Txn[]; warnings: string[] }>;
export function findRecurring(txns: Txn[], kb: Merchant[]): RecurringSeries[];
export function assess(series: RecurringSeries[], kb: Merchant[], ctx: Context): { items: Assessment[]; summary: Summary };
export const DEFAULT_CONTEXT: Context;   // claudePlan 'pro', devices [], unused [], hourlyValue 25, overrides {}
```
Pure functions, no DOM, no network. Must handle 10k transactions in < 300 ms.

### Parsing rules
- CSV with or without header; delimiter auto (`,` `;` tab); UTF-8 BOM; quoted fields; `$`, `€`, `£`,
  thousands separators, decimal commas (EU files with `;`), parentheses negatives, trailing `CR`/`DR`.
- Column synonyms (case-insensitive): date: Date, Transaction Date, Trans. Date, Posting Date,
  Posted Date, Booking Date, Started Date, Completed Date; description: Description, Payee, Merchant,
  Name, Details, Transaction Description, Narrative, Memo (fallback); amount: Amount,
  Transaction Amount, Amount (USD), Value; split columns: Debit / Withdrawal(s) / Money Out / Paid out
  and Credit / Deposit(s) / Money In / Paid in.
- Headerless files (e.g. Wells Fargo: date, amount, *, *, description): infer columns by content.
- Date formats: YYYY-MM-DD, MM/DD/YYYY, M/D/YY, DD/MM/YYYY (detect when any first field > 12),
  DD.MM.YYYY, "Jan 5, 2026", "05 Jan 2026", ISO timestamps.
- Sign convention: output amount POSITIVE for charges. For single-amount-column files decide the
  sign of charges per file: rows whose descriptor matches credit keywords (PAYMENT, THANK YOU,
  AUTOPAY PAYMENT, DEPOSIT, PAYROLL, DIRECT DEP, REFUND, CREDIT, INTEREST PAID, TRANSFER FROM) are
  money-in; the opposite sign is charges; if no keywords, the majority sign is charges.
- OFX/QFX: parse `<STMTTRN>` blocks (`DTPOSTED`, `TRNAMT`, `NAME`, `MEMO`), SGML or XML style;
  TRNAMT negative = charge.
- Multiple files: merge, drop exact duplicates (same date, amount, description).
- Warnings (shown to the user) for skipped rows, unknown columns, ambiguous date order.

### Normalization
Uppercase; strip processor prefixes (`SQ *`, `TST*`, `PP*`, `PAYPAL *`, `PY *`, `SP `, `IN *`,
`DD *`, `CKO*`), card-number fragments, phone numbers, long digit runs (>= 4), reference ids, dates,
URLs paths, trailing US state codes / country codes, words: RECURRING, PURCHASE, POS, DEBIT, CARD,
ONLINE, PAYMENT TO, WWW; collapse whitespace. Keep `APPLE.COM/BILL`, `GOOGLE *<NAME>`,
`AMAZON PRIME`, `AMZN DIGITAL`, `AUDIBLE` etc. recognisable. KB patterns match the normalized string;
also try raw uppercase descriptor if normalized fails.

### Recurrence rules
1. Exclude money-in, and transfers/payments/payroll/ATM/fees/interest/tax by keyword
   (ZELLE, VENMO (person-to-person), TRANSFER, ATM, PAYMENT THANK YOU, INTEREST, FEE, IRS, LOAN,
   MORTGAGE, RENT unless KB-matched). Exclude single charges > $400 unless KB-matched.
2. Group by KB merchant id when matched, else by normalized key (first 3 tokens).
3. Within a group, split into amount clusters (tolerance: max($1.00, 8%)). For KB category
   `telecom-utilities-finance`, allow variable amounts (no clustering, use median).
   Amazon marketplace purchases (AMZN MKTP, AMAZON.COM*) are NOT subscriptions; only KB-matched
   Amazon subscriptions (Prime, Kindle Unlimited, Audible, Prime Video Channels, Music Unlimited).
4. Cadence by median interval: weekly 6-8, biweekly 13-16, monthly 26-35, quarterly 85-97,
   semiannual 175-190, annual 350-380 days. Regularity = share of intervals within tolerance.
   Accept a series with >= 3 charges and regularity >= 0.6, or 2 charges with a matching interval
   and a KB match. A single charge counts only if KB-matched AND equals an `annual` priceHint (±3%).
5. confidence = f(count, regularity, amount stability, KB match). Drop < 0.5.
6. priceChanges: consecutive charges differing > 2% where the new level persists (or is latest).
7. active: lastSeen >= statementEnd - 1.5 * cadenceDays. Inactive series are listed separately
   ("Already gone") and excluded from totals.
8. APPLE.COM/BILL and GOOGLE * charges: each amount cluster is its own series named
   "App Store subscription ($9.99/mo)" with `candidates` = merchant ids whose `billedVia` matches and
   a priceHint within $0.02 of the amount (max 6, most common first). The user can pick one in the UI.

### Assessment rules
- Start from `merchant.verdict`; `ctx.verdictOverrides[key]` wins; `ctx.unused` includes key -> `cancel`.
- Unmatched series -> verdict `keep`, reason "Not in our catalog yet", listed under "Unrecognized".
- `selfhost` needs any of `plans.selfhost.hardware` in `ctx.devices`; otherwise keep the verdict but
  set `blocked` ("Needs an old laptop, Raspberry Pi or NAS") and exclude from savings totals.
- `absorb` with `ctx.claudePlan === 'none'`: savings still counted per item, and Summary adds
  `claudeCostYear` = Claude Pro annual cost once (constant `CLAUDE_PRO_MONTHLY` in assess.ts,
  value taken from the KB `ai` research, source cited in a comment).
- Savings (first year): cancel = annualCost; absorb = annualCost; rebuild = annualCost -
  ongoingCostYear; selfhost = annualCost - powerCostYear; haggle = annualCost * midpoint(expectedDiscountPct)/100;
  rotate = annualCost * monthsOffPerYear/12; keep = 0. Never negative (floor 0).
- Hours: absorb = 0.5, rebuild/selfhost = plan hours, haggle = 0.5, rotate = 0.25, cancel = 0.25, keep = 0.
- Build queue = absorb + rebuild + selfhost items, unblocked first, sorted by roiPerHour desc.

## Knowledge base policy (KB agents and verifiers)
US market, USD. ~35 merchants per category. Facts current as of November 2026; check official
pricing pages with web search; put every URL used in `sources`. If a price cannot be confirmed,
`typicalMonthly: null` rather than a guess.
- **Never** REBUILD or SELF-HOST: password managers, identity/credit monitoring, antivirus,
  banking/brokerage, insurance, medical devices or anything clinical, home-security *professional
  monitoring*, anything holding other people's data (e.g. team tools), licensed content catalogs.
- **Content catalogs** (video, music, audiobooks, news, games): KEEP or ROTATE (video/games are
  rotatable; music usually keep), never REBUILD. Newspapers: HAGGLE (intro-rate retention offers).
- **ABSORB** only when Claude (paid plan, as of Nov 2026) natively does the core job at comparable
  quality for one person: general AI chat duplicates, AI writing/grammar/paraphrasing, summarizers,
  AI slide/doc generators, basic tutoring. Write `limits` honestly (what you lose). Do NOT claim
  features Claude lacks (e.g. if Claude apps cannot transcribe an uploaded audio file, say so and
  route meeting recorders to REBUILD with a local Whisper tool instead). Cite Anthropic docs.
- **REBUILD** only for single-user tools whose value is software you can build in <= 12 hours with
  Claude Code, that run free (static PWA with localStorage/IndexedDB, local script, or free tier),
  with no network effects, no licensed content, no regulated data. Examples: habit tracker, baby
  tracker, simple budgeting, link-in-bio page, meditation timer, workout logger, flashcards,
  personal CRM, booking page (Cal.com OSS is an alternative), form builder for personal use,
  automations (Zapier/IFTTT -> scripts + cron/GitHub Actions). `hours` honest (1-12).
  `youLose` honest (sync across devices, polish, support, integrations).
- **SELF-HOST** only with mature open-source software: Immich, Syncthing, Nextcloud, Jellyfin,
  Home Assistant, Frigate, Pi-hole, WireGuard, Tailscale (free tier), Paperless-ngx, Actual Budget,
  Audiobookshelf, Navidrome, Kavita, Uptime Kuma, etc. `hardware` = devices that can actually run it.
  `powerCostYear` realistic (laptop ~15 W -> ~$22/yr at $0.17/kWh; Pi ~4 W -> ~$6/yr).
- **HAGGLE**: ISPs, mobile carriers, satellite radio, gyms, newspapers, security monitoring,
  insurance. Script <= 120 words, first person, polite, names a competitor offer as leverage.
  `expectedDiscountPct` conservative (e.g. [10, 25]).
- **ROTATE**: pattern like "Subscribe for one month each quarter, binge, cancel".
- **CANCEL** primary only for things most people forget or duplicate (trials, duplicate AI chat
  apps when the user has Claude, etc.); `plans.cancel` is required for EVERY merchant: real steps,
  official URL when one exists, `gotchas` for dark patterns (annual lock-ins, cancel-by-phone).
- `match.patterns`: realistic descriptor regexes (e.g. `NETFLIX`, `HLU\*?HULU|^HULU`, `OPENAI.*CHATGPT|CHATGPT`).
  Never over-broad (`MAX` alone is forbidden; use `MAX\.COM|HBO ?MAX`). `examples` must be realistic
  raw descriptors, matched by your own patterns and by no other merchant's patterns.
- `prompt` fields (absorb/rebuild/selfhost): 80-180 words, paste-ready for Claude Code (or Claude
  for absorb). For rebuild: name the 4-6 core features, storage, platform (installable PWA unless
  noted), import from the old service's export format if one exists, and how to run/deploy free.
  For selfhost: target device and OS, the exact software, backups, remote access via Tailscale.
- Tone: plain, specific, no hype, no exclamation marks.

### Results
- Top bar: statement range, files loaded, warnings (collapsible), "Start over".
- Left column (sticky on desktop; first on mobile): the **receipt** on `--paper`, JetBrains Mono,
  zigzag bottom edge: header "SUBSCRIPTION TAX", statement range; one line per active series
  `name ....... $X/yr` sorted by cost; rule; TOTAL per year and per month; then
  `BUILDABLE (absorb+rebuild+selfhost)  $/yr`, `HAGGLE  $/yr`, `ROTATE  $/yr`, `CANCEL  $/yr`;
  "YOU COULD KEEP $N/yr" and "for about H hours of building"; a decorative barcode built from verdict
  colors. Button "Save receipt as image" (canvas -> PNG download) with a "Hide merchant names" checkbox.
- Right column:
  - Context controls: "Do you pay for Claude?" (No / Pro / Max segmented); "What's in your drawer?"
    device toggles (old laptop, spare PC, Raspberry Pi, NAS, old Android, old iPhone, old iPad,
    Kindle); "Your time is worth $__/hr" (number input). Changing any recomputes instantly.
  - Sections: **Build queue** (absorb/rebuild/selfhost by ROI), **Everything else** grouped by verdict,
    **Unrecognized** (with "Ask Claude about these": builds a prompt containing only merchant
    descriptors, amounts and cadences, copy to clipboard), **Already gone** (inactive).
  - Assessment card: verdict pill; name; amount + cadence; annual cost; price-hike badge
    ("+$3.00 since Mar 2025"); savings/yr, hours, "$/hour of building"; reason; `blocked` notice.
    Expand for the plan matching the verdict: absorb (what Claude does, how, limits, prompt),
    rebuild (what you build, runs on, you lose, prompt), selfhost (software, hardware, you lose,
    prompt), haggle (leverage, script, best time), rotate (pattern), cancel (steps, link, gotchas),
    alternatives. Prompts in a mono block with Copy and "Download build kit" (.md file containing a
    CLAUDE.md-style brief + the prompt). Chips for `also` verdicts switch the card's verdict
    (stored in verdictOverrides). Toggle "I barely use this" (-> cancel). Candidate picker for
    App Store / Google Play bundles.
  - "Export my plan" -> Markdown download of all decisions, savings and prompts.
- Persist Context (not transactions) in localStorage (try/catch). Never persist statement data.
- Accessibility: keyboard reachable, visible focus, aria-live for results, color never sole signal.
